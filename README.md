## 🌟 What's New in v1.1.22

### 1. Interactive 18-Step Journey Navigation
- **Step 15 (Tree Plantation)**: Direct interactive card and one-tap action button (`Open Community Service & Upload Plantation`) leading straight to the activity submission page.
- **Step 16 (Blood Donation & Helping Society)**: Direct link to submit social responsibility initiatives.
- **Full Navigation Support**: Instant routing for **Cohort Timetable (Step 10)**, **Class Attendance (Step 11)**, **Weekly Assignments (Step 12)**, **Skills Training (Step 13)**, **Capstone Project (Step 14)**, and **Official Certificate (Step 18)**.

### 2. Multilingual Voice Assistant & App Actions
- Native built-in shortcuts for Google Assistant and Android system search.
- Multilingual Natural Language Processing in **English**, **Hindi (हिंदी)**, and **Telugu (తెలుగు)** with automatic Text-to-Speech locale switching (`en_US`, `hi_IN`, `te_IN`).
- Live voice status check for verified tree plantations and attendance records.

### 3. Dynamic Intent & Notification Deep-Linking
- Hardened `setIntent(intent)` dynamic intent updates for running app instances.
- Tap any Community Service broadcast notification to jump directly into the portfolio.

### 4. Seamless In-Place Update Compatibility
- Dual-signed with cryptographic key rotation lineage (`lineage.bin`) conforming to APK Signature Scheme v3.1.
- All students and mentors on previous versions (v1.0.0 through v1.1.20) can update without uninstalling or losing data.
